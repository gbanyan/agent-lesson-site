# 新手試讀：能否預測結果

狀態：材料已備妥，尚無真人作答紀錄。這不是統計成效測試，也不能由自動檢查替代。

## 施測方式

找沒有用過 Coding Agent 的讀者，以匿名代號記錄。先讓他閱讀「第一次使用 Agent」路徑，再閱讀圖片工作的位置路徑。可以回看課文，不計速度，不要求背英文。

逐題詢問下面的問題，先記下讀者自己的說法，再問「你從哪段內容判斷的？」不要提前解釋答案。記錄需要補充的背景知識、找不到的內容，以及把回覆當作操作成功等誤解。不要記錄姓名、帳號或私人檔案。

## 給讀者的五題

1. Agent 列出練習資料夾中的檔案名稱。原本檔案有被修改嗎？你還會查看什麼來確認？
2. AI 模型在雲端，圖片程式在這台電腦執行。哪台電腦在縮圖？這能不能同時證明圖片沒有被傳出去？
3. Agent 說日期已改好，你只看過修改清單，還沒打開網頁。你接著會確認哪些事情？
4. 原圖都還在，資料夾另外有三張新圖，Agent 也回報完成。哪些是這次工作的結果？怎麼知道新圖符合要求？
5. 修改前沒有留下舊版本或另一份副本，現在檔案被覆蓋了。是否一定能回到原本內容？開始前本來應該確認什麼？

## 供主持人核對

1. 列檔案的範例只取得清單，沒有修改原內容；其他工具是否另做修改仍應查看紀錄。不能推論所有指令都是唯讀。
2. 縮圖由本機圖片程式執行。模型、圖片程式與資料位置是不同問題，本機縮圖不能證明從未傳資料。
3. 開啟修改後頁面核對 9 月 27 日、其他內容、原有連結及窄螢幕版面。看過差異不等於驗證通過；本機檢查也不是發布。
4. 有三張新圖、工具回報與仍保留原圖的狀態。應開啟新圖核對尺寸與內容，工具說成功不是全部證據。
5. 不一定。應在修改前找到可開啟的舊版本或副本，確認範圍與取回方法；不能事後假設能復原。
