# 教學連續性審查（2026-09-05）

本輪依使用者附件進行。以下是編輯判斷與可重現的檢查範圍，不是新手理解成效證明。

後續全站檢查修正：五條路徑補足逐步銜接；可搜尋的單頁自行交代照片任務，不假定先讀過主線。F3 以登入密碼分享代替自動排程前提，D6 固定圖片程式與照片副本，F3／E7 的警示先於危險要求。入門的 E1 移到 D2 前，第 4 步先確認恢復來源，第 5 步才說明工具動手。這些規則有內容驗證與瀏覽器回歸測試；DOCX 與作者前言仍受保護。

## 情境與例外

使用者指出練習網頁突兀，故主線改為想寄照片給朋友、檔案太大，請 Agent 保留原圖、另存縮小版。首頁、路徑與 B4 先交代目的，明說不用準備素材或實作。B1 才引入「照片」與「縮小照片」示意資料夾。D3 檢查一張新圖仍太大，進一步畫質取捨先詢問，不自行上傳或覆蓋原圖。

位置路徑接續同樣三張照片，不再另設網站素材。程式、安裝與執行先說明如何做；位置路徑固定這批圖片，依次看資料、程式、模型、資源與傳送。C3 的兩種做法是明示比較，不是已經上傳的事實。C4 不再把三個位置全部放成並行的大圖，只聚焦本機縮圖與模型決策的差異。

B6 的 DOCX 文字逐字保留；C2 原有 DOCX 圖說與節點保留在同頁的「另外看文件的例子」，讀者可自行展開。這是保護既有內容的例外，主要圖片情境仍先連續呈現。作者前言完全不改。

## 每頁需要哪些背景

| 頁面 | 閱讀前需要理解 | 本輪處理／保留理由 |
|---|---|---|
| A1 聊天與 Agent | 提出問題、讀取回覆 | 保留介面與能力的界線，用照片大小區分說明與實際查看 |
| A2 控制範圍 | 電腦上有不同資料 | 可選細節，主線先用 B1 的具體資料夾說明 |
| B1 檔案位置 | 照片是可保存的檔案 | 在正文解釋檔案、資料夾與位置，不假設知道專案 |
| B2 路徑 | 檔案與資料夾 | 改用照片/photo-1.jpg，說明示意名稱 |
| B9 工作範圍 | 資料夾與檔案位置 | 指定原圖與另存位置，區分工具可觸及及任務授權 |
| B3 程式 | 圖片可以另存一份 | 三種來源留在圖與短答，刪除正文重複列舉 |
| B5 安裝／執行 | 程式實際縮圖 | 準備程式與開始工作分開，保留安裝也會寫入的提醒 |
| B4 工作變化 | 想寄照片但檔案太大 | 主線起點；先跟資料走，再為輸入／處理／輸出命名 |
| B8 文字操作畫面 | 查看資料夾 | 終端機、指令、回傳名稱放在同一畫面，只有一行指令 |
| B6 讀取／修改 | 文件章節 | DOCX 原文保護；路徑說明這是刻意換例比較 |
| C1 本機／遠端 | 圖片與電腦 | 接續縮小照片的工作，說清位置詞不代表傳送已發生 |
| C2 資料位置 | 原圖與新圖 | 同一批圖的本機位置與線上結果；DOCX 例子可另展開 |
| C3 程式位置 | 圖片程式 | 比較兩台電腦的執行方式，固定原圖與另存要求 |
| C4 模型位置 | 程式負責縮圖 | 模型決定操作與程式執行分開，不用摘要會議記錄換故事 |
| C6 資源 | 本機執行圖片程式 | CPU、記憶體、儲存空間仍各有具體工作，不增硬體採購背景 |
| C5 資料傳送 | 本機與遠端 | 改為獲准上傳三張圖；移除 issue、log、團隊協作的背景負擔 |
| C7 公開 | 新照片已另存 | 新圖尚未寄出，寄信／分享另行確認 |
| D1 可用資訊 | 照片資訊、大小與清晰度要求 | 說明存在電腦不代表已讀到；工具回報進入下一輪 |
| D2 工具 | 提出修改要求 | 實際寫入才改檔，回報與實際內容分開；英文移到正文 |
| D3 工作循環 | 工具與回報 | 取得檢查失敗作為新資訊，保留停止及重新授權 |
| D4 權限 | 讀原圖與另存新圖 | 只授權另存資料夾，允許不代表寫入已成功 |
| D5 管理員權限 | 一般權限範圍 | 題目先問會多開放哪些位置，保留較大影響的界線 |
| D6 工具限制 | 工具能採取動作 | 用活動範圍提問，沙箱名稱放在解釋中 |
| E1 恢復來源 | 原內容與新內容 | 合併修改前準備與能否復原；從保留原圖重做 |
| E2 備份 | 原資料可能出事 | 另存縮小版不等於完整原圖備份，保留同磁碟損壞限制 |
| E3 同步 | 另一處的副本 | 照片資料夾若另開同步，刪除也可能傳送 |
| E4 版本紀錄 | 存過原內容 | 明示轉到修改文章，再以 Git 作工具例子；查看與恢復分開，保留備份界線 |
| E7 外部影響 | 行事曆、通知等日常操作 | 保留外部變化不能靠本機還原撤回的安全觀念 |
| F1 修改差異 | 原要求保留原圖 | 只回答哪些地方改了，操作檢查另由 F2 教 |
| F2 驗證成果 | 另存的新照片 | 同一次驗收，核對大小、完整與清晰度，容許未通過結果 |
| F3 秘密資料 | 密碼與個人資料 | 保留原安全內容，避免擴寫工程工作流程 |
| F4 網路 | 收到或送出資料 | 保留雙向資料流與外部內容不能自動當指令的界線 |

`newTerms` 是作者登記，不是理解難度證明。窄範圍詞彙檢查能阻擋 workspace、project、issue、log 回流到課文；不能偵測所有隱藏前提。真人作答仍需依 `READER_TRIAL.md` 收集。
