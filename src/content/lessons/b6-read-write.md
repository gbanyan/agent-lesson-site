question: 讀取和修改有什麼不同？
answer: 讀取是取得資訊；修改會讓檔案或系統的狀態改變。
takeaway: Read 幫 Agent 知道現況；Write 會改變現況，確認時要分清楚。
newTerms: [Read, Write]
prerequisites: [B1]
visual: { type: concept, preset: read-write }
example: 打開 notes.txt 看內容是讀取；把其中一句換掉是修改。
notTeach: [檔案權限位元, 系統呼叫]
---
兩者都可能是工作需要，但影響不同。重要修改前，應先知道改的是什麼，以及是否有恢復方式。
