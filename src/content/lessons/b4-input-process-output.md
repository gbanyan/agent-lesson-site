三種請求，同一個看法：

請它把會議錄音整理成逐字摘要：輸入是錄音檔，加上「一頁內、結論分開列」；處理是通讀、挑選、整理；輸出是一段能直接抄用的文字。只說「整理一下」沒給限制，長度與結構它就只能猜。

請它查租屋補助的規定：輸入是問題跟「今年還適用嗎」；處理是搜尋、比對幾份文獻——官網、新聞、部落格講得可能都不一樣；輸出是一版附來源的摘要。搜到官方頁還是部落格，摘要可信度完全不同——搜進來的東西，也是輸入的一部分。

請它把三張照片縮小：輸入是檔名、位置跟約定的大小；處理是圖片程式實際執行；輸出是新圖加一段回報——回報是文字，新圖才是結果。

三條流的共通點：結果有一部分由輸入決定。指令越明確、來源越可靠、該給的資料給齊，處理越有依據。但比較容易對，不等於保證對——最後看輸出，不看描述。

想像 Agent 還能幫你做什麼時（「選工具前」第一篇），就拿這個框架套每個念頭：你想丟進去的是什麼？希望它交出來的是什麼？答得出來，就是可以交給它試試的候補；答不出來，就先跟 AI 聊，邊聊邊把它想清楚。
