question: 這次要把什麼改成什麼？
context: 想像你要寄幾張照片給朋友，但檔案太大。你請 Agent 把選好的三張照片各縮小一份，原圖保留，檢查後再決定是否寄出。
answer: 先看它拿到哪些照片，再看工具如何另存縮小版，最後確認新照片可用、原圖沒被改動。
takeaway: 問清楚拿到什麼、做了什麼，以及哪裡真的改變，再判斷工作是否完成。

scenario:
  request: "把選好的三張照片各縮小一份，方便寄給朋友。原圖不要動，新圖另存，先不要寄出。"
  actions:

這是說明用的例子，不需要準備照片或跟著操作。接下來會沿著這件事，看 Agent 怎麼找到照片、使用工具，以及交出可檢查的結果。

若真的要做，開始前先確認原圖能開啟、新圖不會覆蓋原圖。「縮小」也要說清楚：希望檔案變小，仍要保留多少清晰度？

這幾段也常叫輸入、處理與輸出。結果可能是文字回覆、錯誤訊息或檔案內容的改變；還要另外確認動作有沒有獲得允許、結果是否符合要求，以及能否恢復。
