question: 我的資料在哪裡？
answer: 資料可能存在你的裝置，也可能存在遠端系統；光看畫面通常不能確定。
takeaway: 要知道資料在哪裡，應確認實際儲存位置，而不是只看你從哪個畫面開啟它。
newTerms: [資料位置]
prerequisites: [C1]
visual: { type: concept, preset: data-location }
example: 瀏覽器顯示一份文件時，內容可能是剛從遠端載入，不一定已存成本機檔案。
notTeach: [雲端儲存架構, 快取]
---
同一份內容也可能同時有本機與遠端副本。此時還要確認哪一份是目前版本，以及兩者是否會同步。
