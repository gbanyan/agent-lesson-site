question: Context 是什麼？
answer: Context 是 Agent 目前取得、能用來工作的資訊。
takeaway: Agent 只能根據目前取得的資訊工作，不要假定它永遠記得以前知道的事情。

提供正確檔案、明確要求和新的結果，都可能改變目前 context。重要決定前，可以請 Agent 重新檢查現況。
