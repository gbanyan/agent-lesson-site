question: Agent 說完成，就真的完成了嗎？
answer: 不一定。完成是 claim；你還需要用適合的方式確認結果。
takeaway: Claim 不等於 Verification；重要結果要看可觀察的證據。
newTerms: [Claim, Verification]
prerequisites: [D3, F1]
visual: { type: concept, preset: claim-verification }
example: Agent 說網站可以使用後，可以實際開啟頁面、走過主要操作，並查看測試結果。
notTeach: [測試框架教學, QA 流程]

驗證方式要對準要求。只確認網頁能開啟，不能證明所有連結、手機版或無障礙都正確。
