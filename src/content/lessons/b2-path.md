question: 什麼是路徑？
answer: 路徑是指出檔案或資料夾位置的一串名稱。
takeaway: 路徑回答「是哪一個位置」，讓你知道 Agent 正在指哪個檔案或資料夾。
newTerms: [路徑]
prerequisites: [B1]
visual: { type: file-explorer, preset: path-tree }
example: website/images 指的是 website 資料夾裡的 images 資料夾。
notTeach: [絕對路徑語法, 相對路徑運算]
---
看到一段路徑時，不需要立刻學會所有符號。先沿著資料夾名稱，一層一層確認它指到哪裡。
