question: Agent 是一次把所有事情想完嗎？
answer: 通常不是。它會取得資訊、採取行動、查看結果，再根據結果繼續。
takeaway: 把 Agent 理解成「資訊 → 行動 → 結果 → 繼續」的循環，而不是一次完成的黑盒子。
