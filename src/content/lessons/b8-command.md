question: Command 是什麼？
answer: Command 是用文字表達、請電腦執行的一個操作要求。
takeaway: 看到 command 時，先問它要做什麼、影響哪裡，而不是只看文字是否陌生。
newTerms: [Command]
prerequisites: [B7]
visual: { type: terminal, preset: pwd }
example: 一個 command 可以要求電腦查看目前位置，回傳的文字就是結果。
notTeach: [command 語法教學, shell scripting]
---
不同 command 的影響差很多：有的只讀資訊，有的會修改內容，有的會聯絡外部系統。名稱本身不是風險判斷的全部。
