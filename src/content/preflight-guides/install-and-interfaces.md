Agent 可能出現在網頁、桌面應用程式或 CLI。CLI 是 Command Line Interface 的縮寫，意思是用文字指令操作的介面；它通常開在終端機裡。終端機就像一個文字操作窗口：你輸入一行要求，電腦回傳執行結果。

桌面版通常把選擇資料夾、權限提示和預覽做成按鈕與視窗，對初次使用者比較直觀。CLI 則更容易和其他指令串接，也更清楚顯示執行文字，但你需要看懂目前在哪個資料夾、整行指令會做什麼。兩者可能共用模型，卻不一定有相同工具、功能或權限。

安裝前先確認來源是誰、支援哪個作業系統、需要哪些既有程式，以及安裝是否會要求管理員權限。不要從陌生貼文複製一長串指令就直接執行。官方也可能同時提供應用程式商店、安裝程式或套件管理工具；選你能理解、也知道如何移除的方式。

安裝完成只表示程式已放進環境。第一次啟動時，登入、選擇工作資料夾、開放檔案或網路權限，才真正決定 Agent 可以做什麼。
