Agent 可能在網頁、桌面應用程式或 CLI 裡出現。CLI 是 Command Line Interface 的縮寫，意思是用文字指令操作，通常要在終端機裡開啟。終端機是電腦的文字操作窗口：你輸入一行要求，電腦回傳執行結果。

桌面版通常用按鈕和視窗來選資料夾、顯示權限提示和開啟預覽，初次使用比較直觀。CLI 容易和其他指令串接，執行內容也看得比較清楚；代價是你得知道目前在哪個資料夾，還要看懂整行指令。兩者即使使用同一個模型，工具、功能和權限仍可能不同。

安裝前查看來源和支援的作業系統，再確認電腦是否已經具備所需程式。若安裝過程要求管理員權限，也要弄清楚原因。陌生貼文裡的一長串指令不適合直接執行。官方可能同時提供應用程式商店、安裝程式或套件管理工具，選一種看得懂、也知道怎麼移除的方法。

安裝完成只表示程式已放進環境。第一次啟動時的登入方式、工作資料夾，以及檔案和網路權限，會決定 Agent 可以做什麼。
