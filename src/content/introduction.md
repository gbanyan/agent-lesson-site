## 前言

本站的緣起，是為了周邊朋友，思考如何引領他們入門使用 Agent 做事。

AI 的興起，本該是知識平權的創舉。當它從「回答問題」進一步做到「替你動手把事情完成」，就成了我們說的 Agent；這一步之間，卻似乎總有一段鴻溝。這也許是來自於，知識與資料的邊界模糊、網路世界的變革太快、以及工程師或矽谷文化的傲慢。

無論如何，讓一般人也能用 Agent 做事，不必看知識型網紅炫技，也不必對社群網站時不時分享的「今天又做到了什麼了不起的事」望洋興嘆，是本站的目標。

本站刻意不去追會過期的細節：價格、方案、介面與模型清單一直在變，每一樣都交代，就免不了過期，核心精神反而被淹沒。「前置觀念」那幾頁，只教你怎麼自己去查目前的規格；比這些規格更重要的，是如何用更底層的原理想清楚下一步，這才是本站希望讀者帶走的。多數頁面留了一段可直接複製的 Prompt，用意也在這裡。

至於什麼時候該放手讓 Agent 自己做事、什麼時候該一步一步盯著，本站無法替你決定。這牽涉你的資料、你的工具，與你能承擔的風險，沒有一份教材能替這個決定簽名。本站把做這個決定時手上該有的判斷，一張一張交代清楚；剩下的默契，得你自己跟 Agent 磨。
