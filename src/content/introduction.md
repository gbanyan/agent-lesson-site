## 前言

本站的緣起，是為了周邊朋友，思考如何引領他們入門使用 Agent 做事。

AI, 或者說 LLM 的興起，本該是知識平權的創舉，然而從問答到使用 AI Agent 做事，卻好像總有一個鴻溝。這也許是來自於，知識與資料的邊界模糊、網路世界的變革太快、以及一份來自於矽谷文化或者工程師的傲慢。

無論如何，怎樣讓一般人可以使用 AI Agent 做事，不用看知識型網紅炫技、不用對社群網站時不時分享的「今天又做到了什麼了不起的事」望洋興嘆，是本站的目標。

本站刻意不追細節：價格、方案、介面與模型清單一直在變，交代所有細節，就免不了過期，核心精神反而被淹沒。什麼是比較永恆不變的，如何用更底層的原理思考下一步該怎麼走，是本站希望使用者在 AI 時代更能習得的能力。大多數頁面留有一段可以快速複製貼上的 Prompt，即是此用意。

至於什麼時候該放手讓 Agent 自己做事、什麼時候該一步一步盯著，筆者無法替你決定。這牽涉你的資料、你的工具，與你能承擔的風險，沒有一份教材能替這個決定簽名。本站能做的，是把做這個決定時手上該有的判斷，一張一張交代清楚；剩下的默契，得你自己跟 Agent 磨。
