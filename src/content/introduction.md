本站的緣起，是為了周邊朋友，思考如何引領他們入門使用 Agent 做事。

AI, 或者說 LLM 的興起，本該是知識平權的創舉，然而從問答到使用 AI Agent 做事，卻好像總有一個鴻溝。這也許是來自於，知識與資料的邊界模糊、網路世界的變革太快、以及一份來自於矽谷文化或者工程師的傲慢。

無論如何，怎樣讓一般人可以使用 AI Agent 做事，不用看知識型網紅炫技、不用對社群網站時不時分享的「今天又做到了什麼了不起的事」望洋興嘆，是本站目標之一。

然而，本站也有一部分核心精神，是希望，不用太過鉅細靡遺交代會隨時間不停快速變動的細節，不用一直更新維護，只交代核心精神，這樣做，也會要求使用者，必須有一定程度的自主查資料、問問題的精神。因此，在大多數頁面，我留有一些可以快速複製貼上的 Prompt, 希望引領使用者自行思考在當前情境下，我還有哪些不懂的，還有哪些問題可以問。

這也反映了，在 AI 時代，我認為使用者必備的良好品質之一是，必須足夠謙遜，正確面對自己還有什麼東西不懂並發問，並認知到自己的限制。

筆者無法替使用者決定，什麼時候該放手，讓 AI Agent 自己完全做事，什麼時候該信任 AI Agent 的展示資料，不一步一步盯著做事。這些牽扯到不同領域知識，既有模型以及資料庫的變化，以及使用者的自身能力與資料洪流的交互。但筆者認為，開始使用 AI Agent 做事，那麼自己逐步建立個人與 AI Agent 的默契，以及建立自己的認知模型，了解資料如何被處理、運用、產出，並如何以不同的型態交付到使用者手上，仍舊是使用者的責任以及義務。
